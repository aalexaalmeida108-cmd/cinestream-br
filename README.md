# 🎬 CineStream BR

Streaming de filmes e séries com preferência de dublagem em Português Brasil.

## Funcionalidades
- Catálogo de filmes e séries (dados TMDB)
- Player integrado com múltiplos servidores (vidsrc, multembed)
- Preferência de dublagem PT-BR
- Favoritos (localStorage)
- Busca, filtros por gênero e ordenação
- Tema claro/escuro
- Layout responsivo

## Uso local
```bash
python3 -m http.server 8099
```

## Deploy
GitHub Pages — branch `main`, root.
